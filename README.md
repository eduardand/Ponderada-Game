# 🕹️ Jogo de Coleta de Moedas - Phaser.js

Este é um pequeno jogo desenvolvido com **Phaser.js**, onde o jogador controla um personagem para **coletar moedas** e aumentar sua pontuação. As moedas **desaparecem ao serem coletadas** e **reaparecem em novas posições** após um curto intervalo.

## 🎮 **Como Jogar**
1. Use as **setas do teclado** para mover o personagem:
   - **←** Esquerda.
   - **→** Direita.
   - **↑** Pular.
2. Ao tocar em uma **moeda**, a pontuação aumenta e uma **nova moeda** aparece.
3. O jogo continua até atingir a condição desejada (5 pontos).



## 🚀 **Funcionalidades**
- **Movimentação do personagem** com física arcade.  
- **Moeda estática** que some ao ser coletada e reaparece em outro lugar.  
- **Pontuação dinâmica** exibida na tela.  
- **Gerenciamento de colisões** entre personagem e objetos.
